# Legacy Scripts

This directory contains deprecated or legacy scripts that have been retained for backwards compatibility or historical reference.

Policy:
- Legacy scripts are moved here to reduce clutter in `scripts/` and to make the active workflow clearer.
- Files here may be removed in a future cleanup after a deprecation period.

If a script in this folder is required for your workflow, consider copying its essential code into a supported module under `src/` and adding tests.
